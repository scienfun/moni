# 맥 단축어 만들기

`.shortcut` 파일은 토큰이 들어가고 서명이 필요해서 저장소에 넣지 않았다. 단축어 앱에서 아래 순서로 만든다. `<토큰>`은 `bridge/.env`의 `MONI_CLIENT_TOKEN`이다.

1. `URL의 콘텐츠 가져오기`: `http://127.0.0.1:8765/v1/listen`, 메서드 POST, 헤더 `Authorization: Bearer <토큰>`, JSON 본문 `client`=`mac`
2. `텍스트 받아쓰기`: 언어 한국어
3. `URL의 콘텐츠 가져오기`: `http://127.0.0.1:8765/v1/command`, 메서드 POST, 같은 헤더, JSON 본문 `text`=받아쓴 텍스트, `client`=`mac`
4. `사전 값 가져오기`: 키 `speak`
5. `텍스트 말하기`: 한국어 음성
6. 단축어 상세 정보에서 키보드 단축키 지정(예: ⌃⌥M)

연결 실패 시 "모니가 자는 중이에요"를 말하도록 3단계 뒤에 `만약` 동작을 추가한다.
